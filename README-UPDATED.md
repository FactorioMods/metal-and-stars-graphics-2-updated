# Metal and Stars graphics 2: Updated

Provides the additional original Metal and Stars graphics under the maintained dependency identity, including the custom planet artwork used by compatible renderers.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using metal-and-stars-graphics-2 can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ metal-and-stars-graphics-2 ](https://mods.factorio.com/mod/metal-and-stars-graphics-2). Original author credits and applicable license notices are retained in the source package.
